📌 Project Overview

ThreatNexus AI is a Flask-based cybersecurity dashboard that visualizes cyber threats using interactive analytics, AI-powered threat assessment, live monitoring, and global threat intelligence.

🚀 Key Features

  • Live Threat Feed
  • Global Threat Map
  • AI Threat Intelligence
  • Analytics Dashboard
  • Threat Reports
  • CSV & PDF Export

💻 Technologies

  • Python
  • Flask
  • HTML5
  • CSS3
  • JavaScript
  • Plotly

📊 Dataset

The dashboard analyzes simulated cybersecurity threat data, including attack severity, attack type, geographic origin, timestamps, IP addresses, and AI-generated threat insights.
